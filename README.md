# 📊 Amazon Sales Dashboard

> Interactive data analytics dashboard analyzing Amazon India sales data (2019–2022) with drill-down filters, multi-tab navigation, and real-time chart updates.

🔗 **Live Demo:** https://vivek-cyber174.github.io/amazon-sales-dashboard

---

## 📌 Project Overview

This project performs end-to-end exploratory data analysis on Amazon India sales data. It visualizes key business metrics including revenue trends, category performance, geographic distribution, and return rate analysis through an interactive dashboard.

---

## ✨ Features

- 🔍 **Drill-Down KPI Cards** — Click any card to see detailed breakdown (Revenue, Orders, AOV, Returns)
- 🔘 **Dynamic Filters** — Filter by Year (2019–2022) and Category — all charts update instantly
- 📑 **4 Navigation Tabs** — Overview, Products, Geography, Insights
- 📦 **Product Table** — Click any row for monthly sales breakdown
- 💡 **9 Business Insights** — Actionable recommendations based on data
- 📱 **Responsive Design** — Works on mobile and desktop

---

## 📊 Key Insights

- 📈 **Festive Season** drives 34% higher sales in Oct–Nov (Diwali + Big Billion Days)
- 🗺️ **Maharashtra** leads with 22% of total revenue
- 📦 **Amazon FBA** orders have 3x lower return rate vs Merchant fulfilled
- 👗 **Apparel** dominates at 42% of total revenue
- 💰 **AOV grew 38%** from ₹1,840 (2019) to ₹2,540 (2022)
